# 📦 Análise de Estoque Mínimo | Excel

### Sobre o projeto

Projeto desenvolvido para praticar técnicas de limpeza, tratamento e análise de dados no Excel, com foco no controle de estoque e na identificação de produtos que necessitam de reposição.

O objetivo é transformar dados brutos de estoque em informações úteis para apoiar decisões de compra e evitar a falta de produtos.


### Ferramentas utilizadas

Microsoft Excel

Fórmulas e funções do Excel

Limpeza e tratamento de dados

Análise de dados


### Etapas do projeto

Validação dos dados: verificação de SKUs duplicados e identificação de valores zerados no estoque mínimo.

Tratamento dos dados: análise de inconsistências cadastrais que poderiam comprometer os resultados.

Identificação de reposição: criação de uma flag para identificar produtos com o estoque zerado.

Cálculo do GAP: cálculo da diferença entre o estoque mínimo e o saldo disponível.

Priorização: filtragem dos produtos que necessitam de compra e ordenação conforme a necessidade de reposição.


### Resultados

A análise permitiu identificar produtos que atingiram ou ficaram abaixo do estoque mínimo, calcular suas necessidades de reposição e organizar os dados para facilitar a priorização de compras.
